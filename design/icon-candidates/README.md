# Codex Session Atlas 图标候选

最初四款候选采用相同的石墨灰、灰白和低饱和绿色，优先比较图形所表达的功能。用户随后选定 A「会话监控」，并要求白底。选定版本为 a-session-monitor-white.svg，已用作应用图标；原始候选保留用于对比。

| 候选 | 主要图形 | 表达的功能 | 取舍 |
| --- | --- | --- | --- |
| A 会话监控 | 多个对话窗口与执行节点 | 多会话观察、执行过程与活动状态 | 最适合覆盖整个软件；对话符号仍有聊天应用联想 |
| B 执行轨迹 | 执行主线与分支节点 | 工具执行、子任务和 Agent 协作 | 开发工具属性鲜明；也可能让人想到 Git 工具 |
| C 上下文分析 | 分层内容与占用分段 | 上下文组成、材料分析与容量 | 分析用途明确；轨迹与协作的含义较弱 |
| D 会话观察 | 对话气泡与放大镜 | 查看会话、检查记录与排查问题 | 观察用途直观；对上下文组成的表达较弱 |

推荐 A 作为整体产品图标。若优先考虑使用者一眼理解“查看与排查会话”，可以选 D。

旧版使用层叠页面表示上下文，用转折线表示执行轨迹。这种表达依赖解释，也容易被理解为文件管理，因此本轮把会话或分析对象放入主要图形。

候选均为原生 SVG，可复用现有图标构建流程。渲染产物位于 build/icon-candidates；comparison.png 展示四款大图及 32、48、64 像素缩小预览。

候选阶段已使用现有 render-icon.swift 验证四款的透明边角与画布占用范围，并人工检查对比图。白底定稿沿用相同轮廓，反转前景与背景的明暗，以保持小尺寸辨识度。
