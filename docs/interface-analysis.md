# 界面与分析设计 · 0.7.1

面向本地 Agent 使用者，页面需要帮助定位执行问题和上下文增长的证据。参考用户指定的原生 Codex 风格，采用克制的中性色、紧凑导航和文档式内容层级。本次没有直接读取或复制 Codex 本体界面；界面工具拒绝访问该应用。

## 视觉结构

主区为白色 #FFFFFF，侧栏为浅灰 #F7F7F5，摘要背景为 #F5F5F3，正文为 #242424，辅助文字为 #6B6B67，分隔线为 #E7E7E3。保留系统默认字体：主要标题 19–20 pt，正文 12–13 pt，时间为等宽数字。常规导航和操作不再使用蓝色大底或卡片边框。

    浅灰任务侧栏       白色内容区
    Codex Session Atlas        任务标题、项目与运行状态
    搜索与任务列表     概览  上下文  轨迹  协作
                      当前页的图表与筛选
                      类别 / 时间
                      记录标题、可读摘要
    观测状态与版本     必要的体积或耗时信息

应用名称、设置、任务总数及观测状态收进侧栏，避免全宽工具栏叠加任务标题。任务页头与正文共用 1000 pt 最大宽度和水平留白，不再使用一条横线切开导航与内容。选中页签使用浅灰底。上下文和轨迹去掉与页签重复的大标题。

章节通过标题与留白组织，移除通用面板底线、逐条记录横线和概览中间竖线。图表轴线、搜索输入边界和组成色块间隙保留，因为它们表达具体的控件或数据关系。

上下文材料和轨迹共用一套记录排版：类别图标与文字、右侧时间、内容标题、两行摘要和少量元信息。颜色用于识别类别；整行仍可点击。对于完整 JSON 字符串，摘要优先读取已有的标题、命令、查询等文本；参数被截断时只显示可确认的类型提示，不拼接或猜测丢失内容。工具返回预览略去开头的通用执行包装，截断警告仍保留。原始记录和来源始终可展开。

正文阅读器使用白底，区分标题、段落和代码块；结构化对象按字段展示，代码保持等宽。正文、原始记录、复制和分页入口集中在底部；来源路径、日志位置和分类解释收在「来源与记录信息」。原始数据、采集范围与统计口径没有改变。

概览仍使用共同的浅灰摘要区，两列等高，入口置底；窄布局回退为纵向。百分比与进度条均表示已用容量，剩余量单独以 Token 呈现。

## 分类颜色与点击区域

类别仍使用 0.4.0 的独立深色，但限制在图标、类别文字、比例条和选中分类的细标记上。规则为灰，技能为紫，环境为棕，输入为蓝，回复为玫红，调用为橙，返回为青绿，摘要为橄榄绿，附件为蓝灰。不同颜色同时配合图标与名称。

常用按钮保留最小 36 pt 高度，主导航为 40 pt，列表为整行点击，类别为整块点击。视觉变轻不缩小可点击区域。

## 名称与解释

| 名称 | 含义 |
| --- | --- |
| 上下文使用率 | 最近采样的已用 Token ÷ 窗口容量 |
| 已记录内容的文本占比 | 所选范围某类可读字符数 ÷ 全部可读字符数 |
| 内容明细 | 可打开阅读的本地记录内容及来源 |
| Token 消耗 | 最新请求、当前轮次和任务累计的用量 |
| 首次压缩前 | 第一次上下文压缩之前的整个阶段 |
| 可用技能说明 | 技能介绍和调用条件，不是实际执行清单 |
| 运行环境信息 | 目录、时间和插件等描述，不是健康检测 |
| 工具调用内容 | Agent 要求工具执行的操作 |
| Agent 回复与进展 | 已生成的答复与进展说明 |

「这些数字怎么看」提供三种统计口径的就地解释。每个分类都有解释文字：悬停可读，选中后在内容明细展示，正文弹窗也展示同一解释。工具读取的 Skill 文档归入工具返回；本版不猜测其执行归属。

## 分析边界与后续方向

相邻采样只比较同阶段、同模型和同容量的数据。新增内容来自日志位置截取，不等于精确 Token 归因。读取未完成时，顶部显示覆盖提示。轨迹排行仅针对已加载记录；Token 消耗使用任务最新用量，不随历史采样位置变化。

后续仍需补齐：跨任务的启动负担基线、Skill 实际加载与执行关联、全文重复检测，以及有统一验收要求的优化前后质量与效率对比。这些能力未在本版实现。
