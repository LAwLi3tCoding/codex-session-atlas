Codex Session Atlas is a native macOS monitor for local Codex sessions, execution traces, context materials, token usage, and subagent activity.

## Download

Choose `Codex-Session-Atlas-0.8.0-macos-universal.zip` for Apple Silicon or Intel, unzip, and move the app to Applications. Requires macOS 13+. The matching `.sha256` verifies download integrity. The app UI is currently Simplified Chinese.

[Installation (English)](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.md) · [中文安装手册](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.zh-CN.md)

Community build: ad-hoc signed, not Apple-notarized. See the installation guide for first-launch instructions. No API key or compiler is needed for the ZIP.

## Changes

- Default sidebar ordering now uses recent execution activity, with the same timestamp shown in the row. Catalog time is a fallback only when execution evidence is missing.
- Child activity moves its parent group up, including collapsed groups. “Attention first” is an explicit saved option; old alerts no longer force default ordering.
- Unified Codex Session Atlas name, white session-monitor icon, and repository layout.
- Includes the context explorer, paged execution traces, collaboration view, attention evidence, and the prior lifecycle-filter responsiveness and stale-running-state fixes.
- Added English/Chinese READMEs, installation and user guides, data/privacy explanations, MIT license, contributor/security guidance, and a checksum-verifying installer.
- Universal packages are built from the tagged source by GitHub Actions.
