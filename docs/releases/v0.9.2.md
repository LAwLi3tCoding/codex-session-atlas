# Codex Session Atlas 0.9.2

The collaboration list now shows each agent's reasoning effort alongside its model. Subagents also show their task title when available. When the title is missing, the list shows the recorded task name instead, explicitly labeled as a task name. Encrypted or unavailable assignment text is not reconstructed.

协作列表新增每个 Agent 的推理强度。子 Agent 同时显示已有的任务标题；标题缺失时显示记录中的任务标识，并明确标注为「任务标识」。加密或缺失的完整任务说明仍保持未知。

Download the universal archive for Apple Silicon and Intel Macs running macOS 13 or newer. Quit the app before updating. Extract the ZIP, replace the application, and reopen it. Builds are ad-hoc signed and are not Apple-notarized; macOS may require Open Anyway in Privacy & Security.

通用安装包支持 Apple Silicon 和 Intel Mac，要求 macOS 13 或更新版本。更新前退出应用，解压 ZIP、替换应用后重新打开。应用采用临时签名，未经 Apple 公证；macOS 可能需要在「隐私与安全性」中选择「仍要打开」。

See the [installation guide](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.md) or [安装手册](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.zh-CN.md). The checksum-verifying installer uses the latest release automatically.
