# Codex Session Atlas 0.9.1

This update corrects the Dock icon proportions. The white tile is 6.4% smaller, with more transparent padding and softer corners. The session bubbles, execution path, and white background are unchanged. Every icon size in the application bundle is generated from the corrected SVG.

本次更新修正了 Dock 图标的比例：白色底板缩小约 6.4%，增加透明留白，并调整圆角。会话气泡、执行轨迹和白色背景保持不变。安装包内的各尺寸图标均由修正后的 SVG 生成。

Quit the app before updating, replace the old application, and reopen it. If a pinned Dock shortcut still displays the cached icon, remove that shortcut and drag the updated application back into the Dock.

更新前请退出应用，替换旧版后重新打开。如果 Dock 中固定的快捷方式仍显示缓存图标，可从 Dock 移除该快捷方式，再将更新后的应用拖回 Dock。

Download the universal archive for Apple Silicon and Intel Macs running macOS 13 or newer. Builds are ad-hoc signed and are not Apple-notarized. See the [installation guide](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.md) or [安装手册](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.zh-CN.md).
