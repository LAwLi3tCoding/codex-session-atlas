# Codex Session Atlas 0.9.0

The native macOS app now supports English and Simplified Chinese throughout its interface. Open **Settings → Language / 语言** (or press **⌘,**) to switch immediately. Your choice is remembered; system language is also available.

Navigation, context categories, attention explanations, loading/error messages, notifications, app menus and display formats follow the choice. Current tasks, filters and historical samples stay selected. Session titles, messages, tool arguments/output and other source evidence remain in their original language.

Detail pagination now uses explicit page state, so source text cannot accidentally expose or hide the next-page button. Open details refresh safely during language changes.

Applications upgraded from an earlier version may rebuild parsed checkpoints once. Source sessions, seen markers and collected usage history are retained.

应用现已支持简体中文和英文。点击「设置 → Language / 语言」，或按 **⌘,** 即可切换，立即生效并记住选择。页面、分类、告警、提示、通知和应用菜单均随语言更新；会话原文、代码与工具输出保持原样，当前筛选和历史采样不会重置。

Download the universal archive for Apple Silicon and Intel Macs running macOS 13 or newer. Builds are ad-hoc signed and are not Apple-notarized. See the [installation guide](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.md) or [安装手册](https://github.com/LAwLi3tCoding/codex-session-atlas/blob/main/docs/installation.zh-CN.md).
