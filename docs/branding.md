# Project identity / 项目名称

- Application: **Codex Session Atlas**
- Repository: **codex-session-atlas**
- Description: Native macOS Codex session monitor for execution traces, context composition, token usage, and subagent activity. Local-first, read-only, no extra model calls.
- Topics: codex, openai-codex, codex-cli, session-monitor, execution-trace, context-engineering, agent-observability, token-usage, macos, swiftui.

Use the complete name in public descriptions. Codex and Session identify the ecosystem and observed object; Atlas describes the combined views of activity, execution, context, and collaboration. The project is independent of OpenAI.

The icon combines overlapping conversation windows, an execution path, and a green activity marker on a white tile. Its source is [AppIcon-1024.svg](../Resources/AppIcon-1024.svg). Build scripts render platform assets; original design candidates remain under [design/icon-candidates](../design/icon-candidates).
